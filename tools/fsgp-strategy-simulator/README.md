# FSGP Strategy Simulator

A single-page tool that tests how a solar car would do over the three days of a Formula Sun Grand Prix event. Set the array, battery, speeds, cloud cover and car, then see the laps, the battery at each flag and the best speed plan found.

Open `index.html` in any browser. No install, no internet needed (fonts are included).

Built for SERRT. Car defaults are example values for a typical single-occupant car, not a specific vehicle. The model is the same one explained in [`../../docs/PHYSICS.md`](../../docs/PHYSICS.md), though this page has its own implementation.

Rules come from the ASC/FSGP 2026 Regulations, Revision B and the FSGP 2025 Regulations, Release C, published by the Innovators Educational Foundation. Check the current revision before relying on a number.
